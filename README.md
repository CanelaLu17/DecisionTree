# DecisionTree

Notebooks en español que explican, paso a paso, cómo construir un **árbol de decisión para clasificación** con scikit-learn (índice de Gini, entrenamiento, diagrama del árbol y predicciones).

## Contenido

- **IrisTree/**
  - `arbol_decision_iris.ipynb`: árbol de decisión con el conjunto Iris (3 especies de flor).
  - `arbol_decision_iris.html`: versión exportada del notebook para verlo en el navegador.
- **WineTree/**
  - `arbol_decision_wine.ipynb`: árbol de decisión con el conjunto Wine (3 variedades de uva).
  - `wine.zip`: datos del conjunto Wine que usa el notebook.

## Requisitos

    pip install scikit-learn pandas matplotlib
